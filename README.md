# Minecraft AFK Bot

Nodejs Minecraft bot za automatsku registraciju i AFK.

## Instalacija

```bash
npm install
```

## Konfiguracija

Otvori `bot.js` i promeni:
- `host` - IP adresa servera
- `port` - Port servera (default: 25565)
- `username` - Minecraft korisničko ime
- `version` - Minecraft verzija

## Pokretanje

```bash
npm start
```

## Šta bot radi?

✅ Uloguje se na server  
✅ Šalje `/register FlameFrags1 Flamefrags1`  
✅ Stoji AFK bez kickanja  
✅ Periodno skače (sprečava AFK timeout)  

## Napomene

⚠️ Koristi na sopstvenim serverima samo!  
⚠️ Proverite pravila servera pre korišćenja!
